# Finwise

Personal finance web application built as a professional portfolio project.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS + shadcn/ui
- React Hook Form + Zod
- Supabase (Auth + Postgres)
- TanStack React Query

## Features (planned)

- Accounts (wallets, banks, cards)
- Transactions (income & expenses)
- CSV import with preview, mapping and deduplication
- Dashboards and insights
- Automatic categorization rules
