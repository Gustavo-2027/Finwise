# Valette

**Valette** is a personal finance web application built as a **professional portfolio project**, focused on clean architecture, scalable patterns and a polished SaaS-like user experience.

The goal of the project is to demonstrate real-world frontend and full-stack skills using modern tools, best practices and production-ready code.

---

## ✨ Tech Stack

- **Next.js** (App Router, Server Components & Server Actions)
- **TypeScript**
- **Tailwind CSS** + **shadcn/ui**
- **Supabase** (Authentication + PostgreSQL + RPC)
- **TanStack Query** (server-driven data fetching patterns)
- **Zod** (schema validation)
- **Lucide Icons**
- **ESLint + Prettier + Husky**

---

## 🚀 Implemented Features

### Authentication

- Secure authentication using Supabase Auth
- Server-side session validation

### Transactions

- Create, edit and delete transactions
- Income and expense support
- Pagination with URL state
- Search with debounce
- Filters by month and type
- Clean empty states and error handling

### Dashboard

- Monthly summary (income, expenses, balance)
- Latest transactions preview
- Quick actions for common workflows
- SSR data fetching with parallel queries
- Skeleton loading states

### UX & Architecture

- URL-driven state (filters, pagination)
- Fully typed APIs (no `any`)
- Accessible and responsive UI
- Reusable UI components
- Consistent SaaS-style layout
